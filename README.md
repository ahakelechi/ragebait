# Rage Quest: The Kind Kingdom

A tiny 16-bit-style browser rage-platformer. No build step, no dependencies —
just open `index.html` in a browser and go.

## Features
- Fake platforms that vanish under you
- Invisible spikes, a fake victory flag, a control-reverser trap
- Checkpoints so you don't restart the whole level every death
- Animated pixel-art hero with a cape, walk cycle, and squash/stretch
- Parallax background (mountains, castle, clouds, stars)
- Hold **Shift** to sprint past the wider gaps
- Chiptune-style sound effects via WebAudio, no audio files needed

## Controls
- Arrow keys / A-D — move
- Space / Up — jump
- Shift — sprint
- R — restart the level

## Run it
Just open `index.html` in any modern browser.
